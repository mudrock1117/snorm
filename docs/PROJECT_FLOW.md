# Domain_NBias_Render_V2 项目整体流程

## 1. 系统架构总览

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              FasterRCNN (主检测框架)                              │
├─────────────────────────────────────────────────────────────────────────────────┤
│  forward(                                                                      │
│      tc_images,              # 输入图像 (B, 3, H, W)                            │
│      img_metas,             # 图像元数据                                          │
│      mode_training,         # 训练模式 (0-12)                                     │
│      moe_mode,              # MoE渲染模式 (0-11)                                 │
│      moe_mark               # 渲染标记 (8=自适应选择)                             │
│  )                                                                              │
└─────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│                              ModuleSet (教师/学生模块)                           │
├─────────────────────────────────────────────────────────────────────────────────┤
│  teacher: ModuleSet(cfg)     # 教师网络                                           │
│  student: ModuleSet(cfg)     # 学生网络                                           │
│                                                                                  │
│  forward() → features → RPN → ROI Head → detections                              │
└─────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           SNorm (空间归一化模块)                                  │
├─────────────────────────────────────────────────────────────────────────────────┤
│  prev_norm()  →  dist_prog()  →  back_norm()  →  back_norm_w_snorm()             │
│                                                                                  │
│  支持渲染模式:                                                                  │
│    - moe_mode=0: 原始SNorm                                                       │
│    - moe_mode=7: ExpoMamba自适应渲染                                             │
│    - moe_mode=8: AHDR渲染                                                       │
└─────────────────────────────────────────────────────────────────────────────────┘
                                      │
                                      ▼
┌─────────────────────────────────────────────────────────────────────────────────┐
│                    EnhancedAdaptiveRender (自适应渲染选择)                        │
├─────────────────────────────────────────────────────────────────────────────────┤
│  核心组件:                                                                       │
│    ├── AHDR渲染器 (Attention Guided HDR)                                        │
│    ├── ExpoMamba渲染器 (低光增强)                                                │
│    ├── 局部质量评估网络 (Quality Evaluator)                                       │
│    └── 软选择机制 (Softmax + Temperature)                                        │
│                                                                                  │
│  输入: (B, 3, H, W) 原始图像                                                     │
│  输出: (B, 3, H, W) 选择性渲染图像                                               │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 2. 训练模式 (mode_training)

| 模式 | 功能 | 描述 |
|------|------|------|
| 0 | 仅检测 | 标准目标检测训练 |
| 1 | 检测+E-Net | 检测+包络网络 |
| 5 | 检测推理 | 用于推理的标准检测模式 |
| 8 | E-Net Loss | 包络网络损失计算 |
| 9 | Render | 渲染训练 |
| 10 | AHDR Render | AHDR渲染训练 (moe_mode=7, moe_mark=moe_mark) |
| 11 | AHDR+SSIM | AHDR+SSIM损失训练 |
| 12 | ExpoMamba+SSIM | ExpoMamba+SSIM损失训练 |

## 3. MoE渲染模式 (moe_mode)

| 模式 | 功能 | 描述 |
|------|------|------|
| 0 | 标准SNorm | 使用标准空间归一化 |
| 4 | 渲染模式 | 渲染特征提取 |
| 7 | **ExpoMamba** | **使用ExpoMamba进行渲染增强** |
| 8 | AHDR | 使用AHDR进行渲染增强 |

### 特殊组合 (moe_mark)

| moe_mode | moe_mark | 功能 |
|----------|----------|------|
| 7 | 8 | **自适应渲染选择** (ExpoMamba + 原始渲染融合) |
| 7 | 10 | 增强版自适应渲染 (局部自适应) |

## 5. EnhancedAdaptiveRender 核心流程

```
输入图像块 (32x32 patches)
    │
    ▼
┌──────────────────────────────────────┐
│        并行双路径渲染                 │
├─────────────────┬────────────────────┤
│    AHDR路径     │   ExpoMamba路径    │
│                 │                    │
│  1. 通道分离    │   1. 线性增强       │
│  2. 局部归一化   │   2. 去噪          │
│  3. 细节增强    │   3. 对比度调整     │
│  4. 色调映射    │   4. 色彩恢复      │
└─────────────────┴────────────────────┘
          │                    │
          ▼                    ▼
    AHDR输出            ExpoMamba输出
          │                    │
          ▼                    ▼
┌──────────────────────────────────────┐
│        局部质量评估网络 (QualityNet)   │
│                                        │
│  输入: [AHDR_out, Exp_out]             │
│  输出: [q_ahdr, q_exp] 质量分数        │
└──────────────────────────────────────┘
          │
          ▼
┌──────────────────────────────────────┐
│           Softmax选择                 │
│                                        │
│  weights = softmax([q_ahdr, q_exp]/T)  │
│  T = temperature (温度参数)           │
│                                        │
│  输出 = w_ahdr * AHDR + w_exp * Exp    │
└──────────────────────────────────────┘
          │
          ▼
┌──────────────────────────────────────┐
│           边界平滑融合                 │
│                                        │
│  1. 高斯模糊 (σ=3)                    │
│  2. 边缘羽化                          │
│  3. 块间接缝消除                       │
└──────────────────────────────────────┘
          │
          ▼
最终渲染输出
```

---

**结论**: 通过在FasterRCNN框架中集成EnhancedAdaptiveRender模块，系统能够根据场景自适应选择最佳渲染方法，显著提升低光环境下的检测性能。
